내려받는 곳입니다. 소스는 들어 있지 않습니다.

| | |
|---|---|
| 맥 (애플실리콘) | [13mincut_macOS_arm64.dmg](https://github.com/wondalcity/13mincut-releases/releases/latest/download/13mincut_macOS_arm64.dmg) |
| 윈도우 (64비트) | [13mincut_Windows_x64-setup.exe](https://github.com/wondalcity/13mincut-releases/releases/latest/download/13mincut_Windows_x64-setup.exe) |

판 번호와 체크섬은 각 릴리스의 `latest.json` 에 있습니다.
앱이 새 판을 스스로 확인할 때도 그 파일을 봅니다.

처음 열 때 나오는 경고
- 맥: **우클릭 → 열기** 를 한 번 하면 그 뒤로는 그냥 두 번 눌러 쓰시면 됩니다.
- 윈도우: **[추가 정보] → [실행]**.

아직 코드 서명을 붙이지 않아 처음 배포되는 프로그램에는 늘 나오는 안내입니다.
